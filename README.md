# SunCan
## 轻松达成《植物大战僵尸》（PVZ）中“我，无尽僵尸”关卡中的“Better Off Dead”挑战成就。/Easily achieve the challenging achievement of Better Off Dead(In I, Zombie Endless level of PVZ).


在《植物大战僵尸》的“我，僵尸无尽”关卡中，这个工具可以利用蹦极僵尸反复偷取同一朵向日葵，从而获得无限阳光效果。轻松达成“头脑风暴”这一具有挑战性的成就。

In the " I, Zombie Endless" level of Plants vs. Zombies, this tool that utilizes the Bungee zombie to repeatedly steal the same Sunflower, thereby obtaining unlimited Sun effect.Easily achieve the challenging achievement of Better Off Dead.
